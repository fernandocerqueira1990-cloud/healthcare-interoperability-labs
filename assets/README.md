# Assets

Este diretório centraliza imagens, diagramas e evidências visuais do projeto.

Estrutura planejada:

```text
assets/
├── architecture/
│   └── diagrams/
└── evidence/
    └── mvp-v0.1/
        └── local-fhir/
```

## Convenção de nomes

Arquivos de evidência devem usar nomes descritivos e ordenados, por exemplo:

```text
01-docker-compose-ps.png
02-capability-statement-http-200.png
03-post-patient-http-201.png
04-patient-search-identifier.png
05-persistence-after-restart.png
```

Nunca adicionar imagens contendo dados reais de pacientes, credenciais, tokens, chaves ou outras informações sensíveis.
